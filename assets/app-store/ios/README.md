# Materiales de App Store para iOS

Esta carpeta reserva materiales específicos de iPhone. Las capturas finales
deben hacerse en un dispositivo iOS o simulador de Xcode después de la primera
build de TestFlight.

Pendientes:

- Capturas de 6,7 pulgadas y otros tamaños que solicite App Store Connect.
- Texto promocional, descripción, palabras clave y subtítulo.
- Icono de App Store de 1024×1024 sin transparencias ni esquinas redondeadas.
- Notas de versión y datos de contacto para revisión.

No guardar aquí certificados, perfiles, claves ni credenciales de Apple.
