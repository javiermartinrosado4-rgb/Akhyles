# Recursos web de Akhyles

`akhyles-hero-statue-v1.png` es la imagen principal para la portada de la web:
una estatua clásica en escala de grises, situada a la derecha, sin texto ni
marcas. Deja una zona oscura amplia a la izquierda para el titular y utiliza un
fondo de verde bosque y salvia, coherente con Akhyles.

`akhyles-hero-machines-v1.png` se conserva como recurso alternativo de la
portada.

Uso previsto en IONOS: imagen de fondo de la primera sección de Inicio, anclada
a la derecha y con una capa oscura suave para conservar contraste del texto. No
sustituye el icono de la aplicación ni contiene datos de usuarios.
