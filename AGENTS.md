## Android visual QA

For every Android visual bug or UI refinement, use `npm.cmd run android:visual` first. It opens the development build with synthetic demo data and supports fast refresh so the owner can inspect the result. Do not create a release APK/AAB for visual iteration; only build a release artifact after the owner has approved the appearance in the fast QA build.
